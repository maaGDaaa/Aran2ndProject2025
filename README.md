# Numerical Analysis — Second University Assignment

A university coursework assignment for the **Numerical Analysis** course at **Aristotle University of Thessaloniki (AUTH)**.

This assignment focuses on function approximation, numerical integration, and forecasting financial time-series values using numerical methods.

## Assignment Overview

### Exercise 5 — Sine Function Approximation

Develop a function that approximates the sine of any angle, simulating the way a calculator evaluates the sine function. Starting from 10 selected sine values, explore three approaches:

- Polynomial approximation
- Spline interpolation
- Least-squares approximation

Compare the accuracy of these methods over the interval **[-π, π]**, plot the approximation error at 200 points, and investigate the number of accurate digits obtained. Non-uniformly spaced sample points may be used.

### Exercise 6 — Numerical Integration

Approximate the integral of the sine function over **[0, π/2]**, using 11 selected points and two numerical integration techniques:

- Simpson's rule
- Trapezoidal rule

Examine the approximation error both theoretically and numerically.

### Exercise 7 — Stock and Cryptocurrency Price Prediction

Use 10 historical daily closing prices for two selected assets (stocks listed on the Athens Stock Exchange or cryptocurrencies) to estimate future closing prices around a specified date in 2025.

- Fit second-, third-, and fourth-degree polynomials using the least-squares method.
- Compare the approximations and their forecasting behavior.
- Predict the next trading session's closing price and a closing price five sessions ahead.
- Discuss the results and identify the dates used for the predictions.

**Important:** The assignment requires implementing the approximation methods independently rather than relying on built-in approximation functions.
